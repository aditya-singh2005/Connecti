# Feature: Meetups

Meetups are the core goal of the Connecti app—translating digital intent into physical interaction.

## Logic Flow
1. **Prerequisite**: Users must be in the same Geofence Zone and have formed a "Connection" (Mutual Match).
2. **Facilitation**: Since the app guarantees both users are currently within the same defined radius (the Geofence), the barrier to meeting up is extremely low.
3. **UI Indicators**: The app can provide UI cues (like a shared chat interface or compass UI) to help connected users find each other within the zone.
4. **Safety**: Because meetups happen in public, predefined Geofence Zones (like cafes or campuses), the inherent physical safety of the interaction is higher than traditional dating apps. Users can also utilize the "Block" or "Report" features if a meetup goes wrong.
